# Stream Overlays

A collection of lightweight, high-performance browser overlays for live streaming on TikTok LIVE, Twitch, and OBS Studio.

## Included Overlays
- **Cozy Ambient Background** (index.html / cozy_ambient_bg.html): Organic diffused ambient lighting background with floating warm dust motes and slow hue transitions.

## Usage in TikTok LIVE Studio
Add a **Link** source with the URL:
